# Data dictionary

Generated by `manage.py data_dictionary` (`make docs`). Do not edit by hand.

**PII** marks personal data under RA 10173: never in fixtures, logs or git; masked in the audit log (ADR-0006); hidden from roles without `view_personal_data`.

Tables built on BaseModel also have: `id` (UUID), `created_at`, `updated_at`, `created_by`, `updated_by`, `deleted_at`, `deleted_by` (soft delete; ADR-0006).
